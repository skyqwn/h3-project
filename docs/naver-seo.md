# 네이버 검색 노출 가이드 (H3 Tech)

네이버 서치어드바이저 등록 이후, "네이버에서 어떻게 더 노출시킬까"에 대한
운영 가이드다. 구글과 네이버는 로직이 다르므로 구글 SEO(코드 쪽 `lib/seo.ts`)와
별개로 관리한다.

## 현황 (2026-07 기준)

- **구글**: `h3-tech`, `에이치쓰리` 등으로 사이트가 상위 노출됨. 기술 SEO
  (metadata, JSON-LD, sitemap, robots)는 이미 잘 갖춰져 있음.
- **네이버**: 서치어드바이저 등록 완료. `h3-tech` 검색 시 사이트가 상위에
  색인되어 있음(동명 해외기업 H3X Technologies가 함께 노출됨).
- 핵심 이슈는 "색인이 안 된다"가 아니라 **"노출 면적을 넓히는 것"**이다.

## 반드시 이해할 것: 네이버 ≠ 구글

네이버는 **자사 콘텐츠(블로그·카페·플레이스·지식iN·지식백과)를 외부
웹사이트보다 위에 노출**한다. 그래서 `.co.kr` 사이트 하나만으로는 브랜드
검색 상단을 점유하기 어렵다. **네이버 안의 자산을 여러 개 만드는 것**이
노출을 늘리는 실질적 레버다.

## 서치어드바이저 초기 세팅 (한 번만)

`요청` 메뉴에서 아래를 제출한다. **한 번 제출하면 이후 네이버가 주기적으로
다시 방문하므로 재제출은 필요 없다.**

1. **사이트맵 제출** — `https://h3-tech.co.kr/sitemap.xml`
2. **웹페이지 수집 요청** — 주요 URL 개별 등록(홈, /about, /products, 각 제품,
   /blog). 하루 제한이 있으니 며칠 나눠서. 초기 색인 가속용.
3. **RSS 제출** — `https://h3-tech.co.kr/rss.xml`

> ⚠️ 서치어드바이저는 **소유확인한 도메인(h3-tech.co.kr)에 속한 파일만**
> 받는다. 네이버 블로그(`blog.naver.com/es_h3`)의 RSS는 `naver.com` 도메인이라
> 제출 대상이 아니다(네이버가 알아서 수집함).

## RSS 자동화 (코드로 처리됨)

`sitemap.xml`과 `rss.xml`은 **고정 파일이 아니라 요청 시 블로그 글(`.mdx`)을
읽어 그 자리에서 생성**된다. 따라서 **글만 추가·배포하면 두 파일이 자동
갱신**되고, 서치어드바이저 재제출도 필요 없다.

### 관련 코드

- `lib/rss.ts` — RSS 2.0 피드 빌더(ko/en 공유). 마크다운 본문을 HTML로
  변환하고, 이미지/링크를 절대경로(`https://h3-tech.co.kr/...`)로 변환한다.
- `app/rss.xml/route.ts`, `app/en/rss.xml/route.ts` — 위 빌더를 호출하는
  얇은 라우트.
- `app/sitemap.ts` — 사이트맵 자동 생성.

### RSS 피드 형식 (네이버 권장 반영)

네이버 도움말이 권장하는 **"이미지 링크가 포함된 본문 전체"**에 맞춰,
글마다 다음을 담는다.

- `<description>` — 짧은 요약(summary)
- `<content:encoded>` — **본문 전체 HTML**(제목·표·인용·이미지 포함)
- 모든 이미지/링크는 절대경로로 변환 → "동일 도메인 URL" 요건 충족

## 노출을 늘리는 실질 레버 (우선순위)

| 순위 | 액션 | 효과 |
| --- | --- | --- |
| 1 | **네이버 스마트플레이스(지도) 등록** | 회사명 검색 시 지도/플레이스 카드가 최상단 노출. B2B라도 인천 서구 사업장 주소로 등록 가능. 가장 강력. |
| 2 | **네이버 블로그(es_h3) 꾸준히 포스팅** | 제품·시공 사례 → VIEW 탭 노출 + 사이트 유입. 주 1~2회 꾸준히. |
| 3 | **지식백과 기관단체사전 등록 신청** | 브랜드 신뢰도·노출 면적 확대. |
| 4 | **보도자료/뉴스** | 신제품·수주 소식을 뉴스 탭에 노출. |

## 키워드 전략 (동명 브랜드 회피)

`h3-tech`, `에이치쓰리` 같은 순수 브랜드어는 해외 동명 기업 및 헬스케어
"쓰리에이치"와 경쟁이라 불리하다. **롱테일 키워드로 실구매 고객을 잡는다.**

- `인천 반도체 자동화 설비`
- `PVC PP 내화학 설비 제작`
- `흄후드 스크러버 제작`
- `에이치쓰리 반도체`, `H3테크 자동화`

블로그 제목·본문, 사이트 콘텐츠에 위 표현을 자연스럽게 녹인다.

## 새 글 올릴 때 운영 플로우

| 단계 | 담당 |
| --- | --- |
| 1. 블로그 글 작성 (`content/posts/{slug}.ko.mdx`) | 운영자 |
| 2. 배포 (git push → Vercel 자동) | 자동 |
| 3. `rss.xml` / `sitemap.xml` 반영 | 자동 |
| 4. 네이버 재수집 | 자동(제출은 최초 1회) |

- **빠른 노출이 필요할 때만** 선택적으로 `요청 → 웹페이지 수집`에 해당 글
  URL을 개별 등록해 수집을 재촉할 수 있다(필수 아님).
- 글은 frontmatter `draft: false`여야 프로덕션 RSS·사이트맵·블로그에 노출된다.
